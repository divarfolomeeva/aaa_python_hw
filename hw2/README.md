# Домашнее задание №2

## Описание
Программа читает файл `Corp_Summary.csv` и формирует один из трёх отчётов:
1. **Иерархия** — для каждого департамента показывает входящие команды.
2. **Сводка на экран** — название департамента, кол-во человек, мин/макс/средняя зарплата.
3. **Сводка в CSV** — то же, что и пункт 2, но записанное в файл `department_summary.csv`.

## Установка зависимостей
Дополнительные библиотеки не требуются. Используется только стандартная библиотека Python.

## Как запустить
1. Убедитесь, что файл `Corp_Summary.csv` лежит в дной папке со скриптом.
2. Запустите скрипт из терминала, передав номер варианта (1, 2 или 3):

```bash
# иерархия департаментов
python main.py 1

# сводка на экран
python main.py 2

# сводка в CSV-файл
python main.py 3
