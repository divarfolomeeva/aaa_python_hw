# Финальный проект: анализ данных о лауреатах Нобелевской премии

## Описание
Проект состоит из двух этапов:
1. Подготовка данных — разбор ответа API Nobel Prize в плоские словари
   (модули `json_dict_processing.py`, `prizes_configs.py`, `laureates_configs.py`).
2. EDA — анализ лауреатов по странам, возрасту награждения и гендерному
   распределению с визуализациями (ноутбук `project_EDA.ipynb`).

## Структура файлов
- `json_dict_processing.py` — общие функции обработки вложенных словарей
- `prizes_configs.py` — конфиг и процессор призов
- `laureates_configs.py` — конфиги и процессоры лауреатов (люди и организации)
- `assert_tests.py` — валидация функций обработки через assert
- `project_EDA.ipynb` — ноутбук с анализом и графиками
- `requirements.txt` — список зависимостей

## Установка зависимостей
Нужен Python 3.9+ и доступ в интернет (данные запрашиваются с API).
